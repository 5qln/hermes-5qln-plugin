# Research Synthesis — Cross-Referencing Multiple K-Research Passes

When two or more independent K-research passes (from different agents, sessions, or passes) cover the same domain, synthesize into a combined artifact that preserves all discoveries and flags coverage gaps.

## Source Tagging Convention

Label every claim, space, archetype, or finding with its origin:

- `[A]` — from pass A only
- `[B]` — from pass B only
- `[A+B]` — present in both passes (confirmed)
- `[DERIVED]` — new from the synthesis itself (not in either source)

This preserves provenance so the reader can trace any claim back to its source pass and assess its independence.

## De-Duplication Rules

1. When both passes name the same space/archetype with different wording, merge under the stronger name and mark `[A+B]`.
2. When passes disagree on priority/size/characterization, present both and note the divergence explicitly.
3. When one pass has detail the other lacks, preserve the richer version and credit the source.

## Coverage Gap Detection

1. List all unique discoveries from each pass.
2. Cross-reference: what did A find that B missed? What did B find that A missed?
3. Flag gaps in the final artifact — these are areas for future research.
4. When gaps reflect methodological blind spots (e.g., one pass searched English only), name the blind spot explicitly.

## Priority Reconciliation

When passes assign different priorities to the same item:

1. If the disagreement is substantive (different methodology, different data), present both rankings and note the divergence.
2. If one pass simply didn't rank an item, mark the ranking as `[DERIVED]` and note it as a hypothesis.

## Composition Order

1. Spaces map (de-duplicated, all passes merged)
2. Archetypes (all preserved — no archetype lost, even if only one pass found it)
3. Priority matrix (combined, with derived entries marked)
4. Language specimens (best-of from all passes, credited)
5. Open questions (de-duplicated, merged, new ones from synthesis added)
6. Cross-comparison table (§ What Each Pass Contributed) — essential for auditability

## Live Example

Session 2026-07-19: two K-research passes on "where threshold-people gather." Pass A (Hermes) found 14 spaces including large spiritual communities (r/Stoicism, r/Meditation, On Being, The Marginalian) and the Creative/Spiritual Emergent archetypes. Pass B (deep agent) found 22 spaces including FIRE/post-exit/deconstruction niches and the liminal Substack ecosystem, but missed the spiritual and creative categories. Synthesis merged into 26 spaces, 7 archetypes (all preserved), with derived priority rankings for the two archetypes pass B missed.
