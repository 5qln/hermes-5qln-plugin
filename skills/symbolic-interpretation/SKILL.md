## The xyzab Transition Gates — One Flow, Five Registers

The five gates don't separate phases — they mark where the SAME current becomes visible in a different register:

```
S ──[x:X]──→ G ──[y:Y]──→ Q ──[z:Z]──→ P ──[a:A]──→ V ──[b:B]──→ next S
```

| Gate | What It Is | Transition | One-Flow Meaning |
|------|-----------|------------|------------------|
| **x** | X — Validated Spark | S → G | The field of inquiry crystallizes the inquirer's interest — α was always latent in ? |
| **y** | Y — Validated Pattern | G → Q | The inquirer's interest extends toward the whole — resonance was always seeking confirmation |
| **z** | Z — Resonant Key | Q → P | Resonance reveals the generative path — ∇ was always present |
| **a** | A — Flow Direction | P → V | The gradient manifests as deliverable — the fruit was always latent in the flow |
| **b** | B — Artifact + ∞0' | V → next S | Manifestation opens new field — the seed was always in the fruit, next S always pregnant in this V |

**Invariant:** No gate opens without human validation. The agent offers candidates; the human confirms presence. The gates don't separate five steps — they're five places the same current surfaces. Each gate held open for the human to FEEL whether the current is actually flowing or the agent is performing.

The learning aligner tracks at each gate: did the transition happen because the current carried it (emergent), or because the agent forced it (mechanical)?

## xyzab State Machine

A standalone Python 3 script (stdlib only, zero dependencies) that tracks the five
transition gates. Any 5QLN kernel tracks which PHASE you're in; xyzab tracks which
GATE must open next.

The script is at `scripts/xyzab_state.py`. Key commands:

```bash
python3 scripts/xyzab_state.py status
python3 scripts/xyzab_state.py gate
python3 scripts/xyzab_state.py open x -c "X: What opened?" \
  --source-tag emergent --signal "human validation" --session-id example
python3 scripts/xyzab_state.py close y
python3 scripts/xyzab_state.py trail
python3 scripts/xyzab_state.py reset
python3 scripts/xyzab_state.py verify
```

State persists to `$XYZAB_STATE_DIR/xyzab_state.json` (default: `~/.5qln/`).
Enforced sequence lock, cascading rollback, cycle counter, per-gate timestamps.
